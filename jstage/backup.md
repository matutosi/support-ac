# J-STAGE の現状の控え方

作成: 2026-09-24 (MATUTOSI_DP)．

全文 XML (FULL-J) で記事を更新する前に，J-STAGE に載っている状態を控える．
更新がうまくいかなかったときに，もとに戻すためのもの．

**手元の登載用 zip (`jstage/work/_bundle/`) は J-STAGE 版と中身が違うので，控えにならない**．
控えは J-STAGE 側のデータから作る．

## 1. 2つの方法

表: 控えの作り方

| | A. 記事ダウンロード (正) | B. `backup_bibj.py` (補助) |
|---|---|---|
| 出どころ | 編集登載システムが持つ登載データそのもの | 公開中の記事ページ (日英) と J-STAGE の PDF |
| 中身 | 書誌 (全文) XML・本文 PDF・電子付録など一式 | 書誌 XML (BIB-J)・PDF・全文テキスト |
| 記事ページに出ない項目 | 含む | 含まない |
| 作る人 | 人間 (ログインが要る) | Claude でも作れる |
| 置き場 | `jstage/work/_backup/<巻>/jstage_download/` | `jstage/work/_backup/<巻>/vegsci.zip` |

**A を正の控えとし，B は A が取れないときの補助にする**．
両方を取っておけば，A と B を照合して抜けを確かめられる．

## 2. A. 記事ダウンロード (編集登載システム)

根拠は『J-STAGE 操作マニュアル (編集登載編)』(UM-01-004，版 3.8，2026-03-26) の
「12.14.3. 記事ダウンロード」(p.163)．
手元の写しは `jstage/work/_sample/henshu.pdf` (本文を抜いたものが `henshu.txt`)．

1. 編集登載システムにログインし，資料 (vegsci) の記事管理画面を開く．
2. 控える巻・号の記事の一覧で，セクションか記事のチェックボックスを選ぶ．
   **[すべて選択] は画面に出ている記事だけが対象**なので，一覧が複数ページにわたるときはページごとに落とす．
3. ダウンロード形式で **「J-STAGE」** を選ぶ
   (本システムに登載している XML 形式でファイル一式が落ちる．PMC・DOAJ は別の用途の形式なので選ばない)．
4. 落とした zip を `jstage/work/_backup/<巻>/jstage_download/` に置く．名前は変えない．

**落とした一式をそのまま上げ直せるかは，マニュアルに明記が無い**．
初回は1号分で，zip の中が別紙2 の形 (`資料コード/巻/号/記事識別子/`) になっているかを確かめる．
形が違えば，上げ直す前に別紙2 の形へ組み直す．

## 3. B. `backup_bibj.py` (記事ページから組み直す)

```
python jstage/backup_bibj.py jstage/work/13/* --out jstage/work/_backup/13
```

- 入力は作業ディレクトリごとの `web/article_ja.html`・`web/article_en.html` (J-STAGE の記事ページ) と
  `<記事識別子>.pdf` (J-STAGE の全文 PDF)．
  **記事ページは新たに読まない** (保存ずみのものだけを使う．J-STAGE に負荷をかけない決めごと)．
  保存が無い巻は，先に `fetch_jstage.py` で日英1回ずつ保存する．
- 手元の原稿や AI の直し (`meta.yaml`・`body.md`) は使わない．
  書誌は `fetch_jstage.py` に保存ずみのページを読ませて作り直す．
- 出力 (`--out`)
  - `vegsci.zip` … 別紙2 の BIB-J．記事ごとに XML (書誌のみ)・PDF・全文テキスト (`.txt`．BIB-J では必須)
  - `web/` … 元にした記事ページの写し (`<記事識別子>_ja.html`・`_en.html`)
  - `README.md` … 記事の一覧・戻し方・限界

### 3.1. XML に入るもの

- 題名・著者・所属・原稿種別・巻号ページ・日付・DOI・ISSN・キーワード・抄録 (日英)
- 原稿種別は和文ページの表示 (「原著論文」「短報」) を取り，英語名と `article-type` は
  `journals/vegsci.yaml` の `article_types` から引く
- 引用文献は J-STAGE の登録どおりの文字列を `<mixed-citation>` に入れる (著者・年などに分けない)
- 本文 (`<body>`) は持たない

### 3.2. 気をつけること

- **J-STAGE の登録では，外国人の著者が英語名だけで和文の並びに無いことがある**．
  13(1):51 は和文が「菊池」1人，英文が SUBEDI・KIKUCHI の2人．
  和英を先頭から組にすると別人が1人になる (菊池 = SUBEDI) ので，
  数が違うときは**和文名を英文の並びの後ろにそろえて**組む．
  組み方は実行時に表示され，`README.md` にも残る．13 巻の2本 (13(1):51・13(2):95) はこれで合った．
  並びが後ろにそろわない記事が出たら，PDF の1ページ目で確かめる．
- **所属の国は記事ページに無いので入れない** (`build_front` は既定で「日本」を入れるので消している)．
- 全文テキストは PDF の文字の層から取る．13 巻のようなスキャンの PDF は OCR の結果で，誤字を含む．

### 3.3. 確かめること

作ったあと，以下を確かめる．

1. XML が J-STAGE の DTD (JATS 1.1) で妥当か．
   スキルの `validate.py` の `check_rules` も使えるが，
   「`out/manifest.json` が無い」「本文から参照されていない文献」は BIB-J では当然出るので読み飛ばす．
2. zip の中の PDF が作業ディレクトリの PDF と同一か (md5)．
3. 記事の本数が J-STAGE の目次 (`jstage/article_ids.csv`) と合うか．

13 巻 (2026-09-24) は 10 本とも DTD 妥当・その他の指摘 0・PDF は同一だった．

## 4. もとに戻すとき

1. 編集登載システムの「記事一括アップロード」で控えの zip を上げる．
   **記事の種類は「本公開記事」** (登載ずみの記事の更新．マニュアル「13. 記事アップロード」p.170)．
2. zip の名前は `vegsci.zip` のまま変えない (別紙2 の規定で `{資料コード}.zip`)．
3. 上げる前に，全文 XML 作成ツールの「XML 検証」で確かめておくとよい．
4. アップロードの処理結果の画面で記事を選んで確定する．不備があればエラーの一覧が出る (別紙3)．

## 5. 置き場

```
jstage/work/_backup/<巻>/
  jstage_download/   A. 記事ダウンロードで落とした一式 (名前は変えない)
  vegsci.zip         B. backup_bibj.py の出力
  web/               B の元にした記事ページ
  README.md          B の一覧と戻し方
```

`jstage/work/` は git で追跡しない．
控えは**全文 XML での更新が済み，公開画面で問題が無いと確かめるまで消さない**．
