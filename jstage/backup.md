# J-STAGE の現状の控え方

全文 XML (FULL-J) で記事を更新する前に，J-STAGE に載っている状態を控える．
更新がうまくいかなかったときに，もとに戻すためのもの．

- **控えは編集登載システムの「記事ダウンロード」で取る** (公式の機能)．
  登載しているデータそのものが落ちるので，記事ページに出ない項目も含む．
- **編集登載システムのログイン画面**: https://www.jstage.jst.go.jp/edit/EX00S010Init
  (記事ダウンロード・記事一括アップロードとも，ここからログインして行う．2026-09-28 記録)

## 1. 記事ダウンロード

根拠は『J-STAGE 操作マニュアル (編集登載編)』(UM-01-004，版 3.8，2026-03-26) の「12.14.3. 記事ダウンロード」(p.163)．

1. 編集登載システムにログインし，資料 (vegsci) の記事管理画面を開く．
2. 控える巻・号の記事の一覧で，セクションか記事のチェックボックスを選ぶ．
   **[すべて選択] は画面に出ている記事だけが対象**なので，一覧が複数ページにわたるときはページごとに落とす．
3. ダウンロード形式で **「J-STAGE」** を選ぶ．
   本システムに登載している XML 形式で，書誌 (全文) XML・本文 PDF・電子付録などの一式が落ちる．
   PMC・DOAJ は外部連携用の形式なので選ばない．
4. 落とした zip を**記事ごとに分けて** `jstage/work/_backup/<巻>_<号>/<記事識別子>.zip` に置く
   (例: `_backup/13_1/13_KJ00006916281.zip`・`_backup/42_2/42_59.zip`．2026-09-28 ユーザ指示)．
   記事識別子は新しい号なら `<巻>_<開始ページ>`，旧号 (NII 由来) なら `<巻>_KJ<8桁>`．
   **落ちてくるファイル名は `download_<日時>.zip`** で，号の記事がまとめて入り，巻・号を含まない．
   中のパス (`vegsci/<巻>/<号>/<記事識別子>/…`) は変えずに記事ごとの zip へ移し，
   名前・CRC・サイズが元と一致することを確かめてから `download_*.zip` を消す．
   落とした日時はフォルダ名に残らないので，中のファイルの日時で見る
   (13〜43 巻の控えは 2026-09-27〜28 に落とした)．

中身は `vegsci/<巻>/<号>/<記事識別子>/` の下に，記事ごとに `<記事識別子>.xml`・`.txt`・`.pdf` の3つ
(2026-09-27 に 13 巻 1 号で確認)．全文 XML のある記事 (2026-09-28 時点では 43(1) の 7 本だけ) は `.html`・`Graphics/` も，電子付録があれば `Suppl/` も入る (6 本)．
全文 XML を上げる前の XML は**書誌だけ** (`<body>` が無い．題名・著者・所属・キーワード・要旨・引用文献) で，
`.txt` は PDF から取った全文の文字．PDF は手元の作業ディレクトリのものと同一だった．

控えには，記事ページに出ない登録ずみの書誌 (著者名のカナ・論文番号・原稿種別など) がある．
控えから全文 XML を作るときは，スキルの `from_backup.py` で作業ディレクトリを用意する (書誌・引用文献・PDF がそろう．`SKILL.md` の手順 0)．
記事ページから始めた作業ディレクトリに登録ずみの書誌だけを引き継ぐときは `merge_backup.py` を使う．

## 2. もとに戻すとき

公開中の記事への全文 XML は「記事訂正 (履歴なし)」で上げ，公開日 (翌日以降) に置き換わる (スキルの `SKILL.md` 手順 6)．

- **公開日の前なら**: 記事管理画面の「訂正未公開」タブで，その訂正記事を削除する (編集登載編「記事削除」．
  未公開の訂正記事はこのタブから削除できる)．公開中の記事はそのまま残る．
- **公開日を過ぎたあと**: **戻し方はまだ確かめていない**．
  - 記事一括アップロードでは戻せない．公開中の記事は「本公開記事」でも「通常公開記事」でも
    EMSGM183E (対応する記事種別の未公開状態ではありません) で止まる (2026-09-28 に 13(1):1 で確認)．
    以前ここに書いていた「本公開記事で上げ直す」は誤り．
  - 記事訂正の「全文XML」は本文・文献・抄録を更新し，他の書誌事項は更新しない．控えの書誌だけの XML で
    本文を消せるか，「全文XML」を削除できるかは未確認 (「履歴なし編集可能項目一覧」ではファイルの削除は履歴なしでは不可)．
    必要になったら J-STAGE センターに問い合わせる．
