# J-STAGE の現状の控え方

全文 XML (FULL-J) で記事を更新する前に，J-STAGE に載っている状態を控える．
更新がうまくいかなかったときに，もとに戻すためのもの．

- **控えは編集登載システムの「記事ダウンロード」で取る** (公式の機能)．
  登載しているデータそのものが落ちるので，記事ページに出ない項目も含む．

## 1. 記事ダウンロード

根拠は『J-STAGE 操作マニュアル (編集登載編)』(UM-01-004，版 3.8，2026-03-26) の「12.14.3. 記事ダウンロード」(p.163)．

1. 編集登載システムにログインし，資料 (vegsci) の記事管理画面を開く．
2. 控える巻・号の記事の一覧で，セクションか記事のチェックボックスを選ぶ．
   **[すべて選択] は画面に出ている記事だけが対象**なので，一覧が複数ページにわたるときはページごとに落とす．
3. ダウンロード形式で **「J-STAGE」** を選ぶ．
   本システムに登載している XML 形式で，書誌 (全文) XML・本文 PDF・電子付録などの一式が落ちる．
   PMC・DOAJ は外部連携用の形式なので選ばない．
4. 落とした zip を `jstage/work/_backup/<巻>/<号>/` に置く (例: `_backup/13/1/`)．
   **落ちてくるファイル名は `download_<日時>.zip`** (例: `download_20260927170406.zip`．日時は落とした時刻) で，巻・号を含まないので，フォルダで分ける．
   名前は変えずに置く (いつ落としたかが分かるように)．

中身は `vegsci/<巻>/<号>/<記事識別子>/` の下に，記事ごとに `<記事識別子>.xml`・`.txt`・`.pdf` の3つ
(2026-09-27 に 13 巻 1 号で確認)．
全文 XML を上げる前の XML は**書誌だけ** (`<body>` が無い．題名・著者・所属・キーワード・要旨・引用文献) で，
`.txt` は PDF から取った全文の文字．PDF は手元の作業ディレクトリのものと同一だった．

## 2. もとに戻すとき

1. 編集登載システムの「記事一括アップロード」で控えの zip を上げる．
   **記事の種類は「本公開記事」** (登載ずみの記事の更新．マニュアル「13. 記事アップロード」p.170)．
2. zip の名前は `download_<日時>.zip` から `vegsci.zip` に変える (別紙2 の規定で `{資料コード}.zip`)．
   控えそのものは変えずに，写しの名前を変えて上げる．
3. 上げる前に，全文 XML 作成ツールの「XML 検証」で確かめておくとよい．
4. アップロードの処理結果の画面で記事を選んで確定する．不備があればエラーの一覧が出る (別紙3)．
