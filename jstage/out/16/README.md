## 使い方 (人間が行う)

zip の中は `vegsci/16/<号>/<記事識別子>/` に XML・PDF・`Graphics/`．

1. 全文 XML 作成ツールで巻号を選び，「インポート」で `<記事識別子>.zip` を読み込む．
2. 「XML 検証」と「プレビュー」で確かめる (公式の検証が最終の判定)．
3. 「エクスポート」で全文形式 (FULL-J) を選び，編集登載の一括アップロードへ上げる．

**まとめて登載する**ときは，作業ディレクトリから1つの zip を作り直せる:

```
python .claude/skills/pdf-to-jstage-xml/scripts/bundle.py jstage/work/16_1 jstage/work/16_13 … --out <出力先>
```

アップロード画面で選ぶ記事の種類は1回に1つ．**PDF だけで公開ずみの記事の更新は「本公開記事」**．
巻・号はアップロードの前に編集登載システムで作っておく．
