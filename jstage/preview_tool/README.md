# preview_tool: J-STAGE の全文 HTML のプレビューを手元で作る

J-STAGE に上げてプレビューするのは時間がかかり，手作業も多い．
全文 XML (JATS 1.1，FULL-J) の zip から，J-STAGE の全文 HTML の画面に似せたページを手元で作る．
**公式の確認 (全文 XML 作成ツールの「XML 検証」，編集登載のプレビュー) の代わりではない**．
上げる前に，見た目と中身 (見出し・段落・リンク・図表・文献) を手早く確かめるためのもの．

## 使い方

```
python jstage/preview_tool/preview.py <入力> [<入力> ...] [--open]
```

- 入力は次のどれでもよい．
  - 記事の zip (`build.py` の `<記事識別子>.zip`)
  - まとめた zip (`vegsci.zip`)
  - 記事ダウンロードの zip
  - 作業ディレクトリ (`jstage/work/<巻>/<開始ページ>/`)
  - XML
- 出力は `jstage/preview_tool/out/<記事識別子>/index.html` (git では追跡しない)．
  記事が複数なら `out/index.html` に一覧ができる．`--open` でブラウザに開く．
- `--lang en` で英語の画面．既定は日本語の画面 (J-STAGE の `-char/ja`)．
- 例: `python jstage/preview_tool/preview.py jstage/work/13/001 --open`

## 見た目 (CSS)

- `_sample/` に J-STAGE の記事ページ (全文) をブラウザで保存してあれば，その `*_files/` の CSS を
  **写さずに参照する** (`--jstage-css <フォルダ>` で指定もできる．`none` で使わない)．
- 無いときは `preview.css` (自前の最小限の CSS) だけで表示する．J-STAGE の CSS はリポジトリに入れない．
- 保存したページには J-STAGE の Web フォントが無く，斜体・太字が付かないので `preview.css` で補っている．

## ページの中身

- **先頭の紫の枠「プレビューの点検」**: J-STAGE の画面には出ない項目と警告．
  - 項目: 記事の ID・原稿種別・題名 (日英)・著者 (日・英・読み)・所属 (住所・国)・キーワード・履歴・license・文献の数と DOI
  - 警告: リンク先の無い引用・画像の欠け・本文から引かれていない文献と図表・表示に対応していない要素
- **見出し部分**: 原稿種別・題名・著者・「著者情報」・巻号とページ・DOI・「詳細」(日付)．J-STAGE の記事ページの組み方をまねた．
- **全文の部分**: 左に目次，右に抄録・本文・謝辞・文献・図表の一覧．
  **クラス名も含めて，J-STAGE が XML から作る全文 HTML に合わせてある** (次の節)．
- DOI (`<pub-id pub-id-type="doi">`) のある文献は，文献全体を `https://doi.org/…` へのリンクにした．
  J-STAGE では公開後の原文問合わせで JaLC などへのリンクが付く (同じ形で文献全体がリンクになる)．

## J-STAGE の全文 HTML との対応 (確かめたこと)

記事ダウンロードの zip には，全文 XML の記事なら J-STAGE が作った `<記事識別子>.html` (全文の部分の断片) が入っている．
これを正として `compare.py` で比べられる．

```
python jstage/preview_tool/compare.py <記事ダウンロードの zip>
```

2026-09-28 に植生学会誌 43(1) の 7 本で，**文献を除く全単位が一致**した (見出し・段落・本文のリンク・画像・図表の id・目次)．
そのために合わせた J-STAGE の扱い:

- **XML の字下げ**: 改行とその後ろの空白は捨て，改行の前の空白は残す．`<ext-link>` の中だけは空白 1 つになる．
- **空の `<p/>`** も空の段落として出る．
- **謝辞は文献の前**に出る (XML の並びによらない)．
- **文献の見出し**は文献の多数の言語で決まる: 和文が多ければ「引用文献」「引用文献(n)」，英文が多ければ「References」「Reference List(n)」．
  XML の `<title>` を使うかは未確認 (43(1) には無かった)．違うときは点検の枠に注意を出す．
- `<disp-quote>` は `<blockquote><p>` (本文の段落のクラスは付かない)．
- MathML の中の字下げは残る．
- 画面の言語の題名・所属を出す．所属が空 (`<aff xml:lang="ja"/>`) ならもう一方の言語．

**分かっている違い (直さない)**:
- 文献の文字: J-STAGE は XML の文字ではなく，登録した文献のデータから組み直す．
  「Krieger , A.M.」のように空白が入り，XML の「DufrêneMLegendreP1997」が「Dufrêne M Legendre P 1997」になる．
  プレビューは XML の文字を出す．
- 43(1) に無かった要素 (`<label>`・`<caption>` の図表，`<table>` の表，数式の画像，箇条書き) は，
  J-STAGE の見本が無いので推測で組んだ．図は画像の下に「**Fig. 1** キャプション」，表は上に「**Table 1** 表題」．

手元の 133 本 (13〜23 巻のまとめた zip) で落ちずに作れ，リンク先の無い引用・画像の欠け・対応していない要素は 0 件だった (2026-09-28)．

## ファイル

- `preview.py` … 本体
- `preview.css` … 埋め込む CSS (J-STAGE の CSS が無いときの見た目と，プレビューだけの部品)
- `compare.py` … J-STAGE が作った全文 HTML との比較
- `_sample/` … 見本 (J-STAGE から保存した記事ページと記事ダウンロード．**git では追跡しない**)
- `out/` … 出力 (追跡しない)
