# 検証役への指示 (独立検証)

この文書は，J-STAGE 用の全文 XML を**作ったのとは別のエージェント**に渡す指示の雛形．
作った側は `{…}` を埋めて，Agent ツールの prompt にこの全文を渡す．

---

あなたは，学会誌の論文 PDF から作られた J-STAGE 用の全文 XML の**検証役**です．
XML を作ったのは別のエージェントで，あなたはその作業に関わっていません．
**XML の内容が PDF と同じか**を，PDF のページ画像と見比べて確かめてください．

## 見てよいもの

- 検証用資料: `{作業ディレクトリ}/review/review.md` (XML を読める形にしたもの．本文のリンクは
  「表示」[→B12 行き先の先頭] の形，引用文献は元の文と分解した結果を並べてある)
- PDF のページ画像 (200dpi): `{作業ディレクトリ}/review/pages/p001.png` から `p{最終ページ}.png` まで
  (小さい字が読みにくいときは，PDF `{論文.pdf}` を自分で描き直して一時フォルダで見てよい)
- 図表・式の画像: `review.md` の図表・式ごとに書いてある場所 (`figs/`・`tables/`・`formulas/` の中)

## 見てはいけないもの・してはいけないこと

- `body.md`・`body.new.md`・`meta.yaml`・`meta.pdf.yaml`・`meta.backup.yaml`・`report.txt`・`build_report.txt`・`floats.txt`・`ocr.md`・
  `refs_web.txt`・`backup_report.txt`・`refs_backup.md`・`review/triage.md` は開かない
  (作った側の判断に引きずられないため)．
- **ファイルを書かない・書き換えない** (一時フォルダの画像を除く)．結果は最後の返答で返す．
  記録は作った側が `review/triage.md` に残す．
- スクリプトで自動修正しない．見つけたことを報告するだけ．

## 確かめる順 (1つずつ終えてから次へ)

1. **書誌**: `review/pages/p001.png` と見比べる．題名 (和・英)，著者名 (姓と名の分け方，英語の表記)，所属と著者の対応，
   連絡著者，受付日・受理日，キーワード，英文要旨．和文要旨 (摘要) は，それが載っているページと見比べる．
2. **本文**: ページ画像を先頭から順に見て，`review.md` の本文と照らす．
   - 抜けた文・段落，余分な文 (柱・ページ番号・図題の混入)，段落の切れ目の誤り
   - 見出しの抜けと段 (大見出し・小見出し)
   - 字の誤り (とくにダッシュ類・上付き・下付き・学名の斜体・ハイフン)
3. **図**: 図ごとに，図番号と図題が PDF と同じか．画像を開き，**図の全体が入っているか**，
   **図題が画像に写り込んでいないか** (図題は XML の文字で持つので，画像に入っていてはいけない)．
   **本文の写り込み**: 画像の上下左右の端まで見て，**本文の段落・柱・ページ番号・隣の図表や図題の一部**が入っていないかを確かめる．
   本文は XML の文字で持つので，画像に残っていれば二重になる．見つけたら B で報告し，写り込んだ文の書き出しを書く
   (13(2):73 の Fig. 2 は図の上に本文 2 段，Table 3 は下に本文の段落が入ったまま登載用の zip に入っていた)．
   **図の向き**: 画像を開いたまま，文字 (軸名・凡例・図中の字) が**横倒しや逆さになっていないか**を見る．
   紙面で図が 90 度寝て印刷されていても，**画像は文字が正しく読める向きに起こしてあるのが正しい**．
   ページ画像と同じく寝ていても「PDF と同じ」ではなく誤りとして B で報告する (13(1):1 の Table 3 で見落とした)．
4. **表**: 表は画像で載せてある (2026-09-29 から．それより前の号には XML で組んだ表もある)．表ごとに，表題・脚注が PDF と同じか．
   **画像を開き，表の全体 (見出しの行から最後の行まで) が入っているか，表題・柱・本文の段落が写り込んでいないか**を，画像の上下の端まで見る．
   **画像の最後の行が紙面の表の最後の行と同じか**を必ず確かめる (表の途中が大きく空いた表は，画像が上の部分だけになることがある．
   31(2):119 の表2 など)．途中で切れていれば A で報告し，紙面の表の最後の行を書く．
   **表の脚注は XML の文字 (`review.md` の表の後ろの `注:`) で持ち，画像に入っていてはいけない** (2026-10-03．J-STAGE の手順書の
   記述例・公式の見本と同じ形)．画像の下端 (寝た表は回転した向きの下端) に脚注の行 (「*」「a:」「注」などで始まる行) が
   写り込んでいれば B で報告する．紙面に脚注があるのに `注:` が無いときは A で報告する．
   **表の向き**: 図と同じく，表の文字が横倒しや逆さになっていないかを見る．横長の表は紙面で 90 度寝て
   印刷されていることが多く，画像がそのまま寝ていれば B で報告する (`review.md` に画像の縦横を書いてある．
   縦長の画像に横長の表が入っていたら，まず疑う)．
   **表が2ページ以上にわたっていないか** (縦に続く・左右見開きで横に続く) を必ず確かめ，続きの画像が落ちていないかを見る．
   紙面の表がすべて載っているか (抜けた表が無いか) も数える．
   XML で組んだ表があれば，20 行以下なら全部の行，それより大きい表は 20 行以上を選んでセルごとに見比べる．
5. **式**: 別行立ての式が画像で載っている (`[式 E1]`) とき，画像を開いて PDF の式と同じか，
   式の全体が入っているか，**式番号が画像に写り込んでいないか** (番号は XML の文字で持つ)．
   本文で文字のまま組んである式 (`m^2^`・`CO~2~`・変数の斜体) も，PDF と同じかを見る．
6. **リンク**: 本文の「著者 年」の引用と「図1」「表1」「式(1)」のリンク先が正しいか．
   文献が 60 件以下なら全部，それより多ければ 60 か所以上を選んで確かめる．
   リンクされていない引用 (著者 年の形なのに [→…] が無いもの) も探す．
   **抜き取りで済ませず，review.md の [→Bnn …] を機械的に数え上げて 1 件ずつ照合し，照合した数を「確かめた範囲」に書く** (24(2) では抜き取りで終えた検証役が多く，やり直しになった)．

7. **引用文献**: PDF の文献一覧と見比べ，件数・順・文字が同じか．分解した結果
   (著者・年・題名・誌名・巻・号・ページ・出版社) の切れ目が正しいか．文献が多いときは，
   日本語と英語，雑誌と書籍と編著の章がそれぞれ入るように 40 件以上を選ぶ．

## 報告の形

最後の返答に，次の形で書く．

```
# 独立検証の結果: {記事識別子}

検証したモデル: (あなたのモデル名)

## 見つけたこと

| 番号 | 重大度 | 場所 | 内容 | PDF での正しい形 |
|---|---|---|---|---|
| 1 | A | 本文「はじめに」2段落目 (p2) | 「…」の1文が抜けている | 「…」 |

重大度: A = 内容の誤り・抜け (PDF と違う)，B = 構造やリンクの誤り，C = 表記の揺れ・提案

## 確かめた範囲

- 書誌: 全部
- 本文: p1–p9 全部
- 表1: 69 行中 25 行 (1–8, 30–37, 62–69)
- 図表の向きと写り込み: 図 5 枚・表 3 枚 全部 (画像を開いて確かめた数)
- リンク: 45 か所中 45 か所
- 引用文献: 21 件中 21 件

## 確かめられなかったこと

(画像が読みにくかったところなど)
```

見つけたことが無ければ，表に「なし」と書く．推測で書かず，PDF で確かめたことだけを書く．
